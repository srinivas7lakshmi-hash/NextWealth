## ⚡ Recruiter & Technical Showcase

This project was engineered specifically as a **high-impact portfolio centerpiece** to demonstrate production-grade frontend architecture, mathematical state modeling, real-time Canvas 2D physics, and enterprise UX design.

### 🎯 Key Engineering Pillars

1. **Interactive Annotation Studio Workbench (Recruiter Magnet)**
   - Simulated interactive annotation sandbox with 4 real-world modalities:
     - 🚗 **Autonomous Driving (ADAS):** Interactive LiDAR 3D cuboids, bounding boxes, object classification (`#car_01`, `#ped_01`), depth sensing, and real-time KITTI/COCO JSON telemetry export.
     - 🧠 **GenAI & LLM RLHF:** Multi-turn legal/risk reasoning audit with side-by-side model outputs, truthfulness scoring, and simulated 3-person specialist consensus verification.
     - 🩻 **Healthcare & DICOM Radiomics:** Simulated thoracic CT scan with toggleable lobar consolidation segmentation masks and board-certified radiologist verification badges.
     - 🛍️ **E-Commerce Visual Intelligence:** Deep taxonomy tagging, attribute extraction (material, silhouette, collar), and merchant compliance scoring.

2. **Real-Time 60 FPS Neural Constellation Canvas (`canvas-bg.js`)**
   - Pure HTML5 Canvas 2D animation with:
     - Mouse gravitational repulsion and spring return physics.
     - Dynamic bezier data packet pulses streaming between neural nodes.
     - Device pixel ratio scaling with zero layout thrashing or dropped frames.

3. **Enterprise Pipeline ROI & TCO Modeler (`roi-calculator.js`)**
   - Real-time mathematical modeling calculating:
     - Onshore/US in-house baseline vs NextWealth Tier-2 managed pod fees.
     - Monthly & annual net cost savings (typically 65%–74%).
     - Turnaround time acceleration (e.g. 4 days vs 18 days).
     - Dedicated full-time specialist headcount allocation.
     - Interactive printable Executive Specification modal.

4. **Lightning Command Palette (`Ctrl + K`) & Modular Event Bus**
   - Keyboard-accessible search modal indexing all services, compliance standards, and demo tools.
   - Event-driven toast notification system (`window.showToast()`).
   - Accessible ARIA labels and semantic HTML5 document tree.

5. **Zero-Build Architecture (Instant 1-Click Execution)**
   - No `npm install`, Webpack, Vite, or Node.js runtime required.
   - Double-click `index.html` and it renders instantly in any modern browser in under 300ms.
   - Ready for instant deployment on GitHub Pages or Vercel.

## 🚀 How to Run Locally

Because this project is built on modern web standards with zero build dependencies, you can run it immediately:

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer. It will open directly in Google Chrome, Microsoft Edge, Safari, or Firefox.

### Option 2: Local HTTP Server (Optional)
If you have Python or VS Code Live Server installed:
```bash
# Python 3
python -m http.server 8080

# Or via VS Code: Right click index.html -> 'Open with Live Server'
```
Visit `http://localhost:8080` in your browser.

## 🌐 Deploy to GitHub Pages in 2 Minutes

To showcase this on your GitHub profile and add it to your resume:

1. **Create a new repository** on GitHub (e.g., `nextwealth-ai-platform`).
2. **Push the code**:
   ```bash
   cd nextwealth-ai-platform
   git init
   git add .
   git commit -m "feat: initial release of NextWealth AI enterprise platform"
   git branch -M main
   git remote add origin https://github.com/srinivas7lakshmi-hash/NextWealth.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - Go to your repository settings on GitHub.
   - Click on **Pages** in the left sidebar.
   - Under **Branch**, select `main` and root `/`, then click **Save**.
   - Your live site will be deployed at: `https://srinivas7lakshmi-hash.github.io/NextWealth/`!
